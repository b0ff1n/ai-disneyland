# Study materials

This is a place to keep links to syllabi, bibliography, your own notes, and small quotes/excerpts to work with.

The local textbooks are cataloged in [library/README.md](../library/README.md), with exact source files, verified edition information, contents, and printed-to-PDF page maps:

- Spivak, *Calculus*, 4th edition.
- Axler, *Linear Algebra Done Right*, 3rd edition.
- Dummit & Foote, *Abstract Algebra*, 3rd edition.
- Kato, Kurokawa & Saito, *Number Theory 1: Fermat's Dream*, English translation by Masato Kuwata, AMS, Translations of Mathematical Monographs 186.

Official materials of future university courses remain to be added once verified.

The learner explicitly requested versioning the four supplied books and retaining their extraction in Git on 2026-10-25. Files in `library/originals/` are tracked through Git LFS; full-text extraction and navigation metadata are ordinary Git files in [library/extracted/](../library/extracted/README.md). Ignored `library/cache/` is for expendable previews only. [MEMORY.md](../MEMORY.md) describes the repository's external memory across machines. A local commit does not publish the books. Pushing or sharing the repository requires a separate explicit request under `AGENTS.md`.
